# stew-c/retro

Homebrew formulae for retro-computing tools that aren't in homebrew-core.

| Formula | Description |
| ------- | ----------- |
| `pasmo` | Portable Z80 cross assembler with ZX Spectrum, Amstrad CPC and MSX output |

## How do I install these formulae?

`brew install stew-c/retro/<formula>`

Or `brew tap stew-c/retro` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "stew-c/retro"
brew "<formula>"
```

No bottles are published, so formulae build from source on install.
